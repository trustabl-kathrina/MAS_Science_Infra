# Plan

在同一张从左到右的树中展示一道题的所有采样：初始 rollout 独立分行，分支从具体执行位置接出，右端显示各自结果。点击普通节点阅读该次 Agent 的真实过程。

状态：代码已接入，核心前端检查和生产构建通过；浏览器视觉与服务器数据待验收。依赖 [第三阶段](RolloutTree执行树第三阶段-树组装与结果读取.md)，复用现有采样结果入口、React Flow 和 UI 风格。

## Requirements

- 新记录默认执行树，回答列表作为结果摘要保留。
- 一个过程节点就是一次执行，不是整个回答，不是 Agent 定义。
- 未分支的初始 rollout 清楚地表现为横向执行链；有分支时公共前缀不重复。
- 节点名称突出 Agent 与执行轮次，rollout/attempt 等技术 ID 放详情。
- 无真实过程的旧记录保留回答列表与旧来源图，不显示假执行树。

## Proposed Architecture

### 布局

```text
题目列表          当前题目                      [执行树] [回答列表]

                  ┌─ hub ─ Python ─ hub ─ 结果 A
             问题 ┤          └───── hub ─ 结果 B（续采样）
                  └─ hub ─ 搜索 ─── hub ─ 结果 C
```

- Query 固定在左侧；多个 initial rollout 按开始顺序上下排列。
- 普通后续节点向右延伸；child 在分支点下方新开路径。不是将整个父回答画在 child 左边。
- 独立补采样从 Query 新开一行，并标来源，不接到其他 rollout 的末尾。
- 分支小标记附在节点出口，连线可显示配置的分支位置；Window/Snapshot 不再占用一张普通节点卡片。
- 并行工具在同一列局部分组，再连接后续节点；和采样分支使用不同标识。
- “一道题所有采样”指同一 run、同一采样组，不把其他训练步或验证记录混在一起。

### 卡片与详情

过程卡片显示 Agent 名、轮次、状态和简短输出。纯工具卡片展示参数/结果摘要；结束卡片显示答案和最终奖励。

```text
hub · 第2次执行                  已完成                [展开阅读] [关闭]

输出与推理
  模型实际返回的 reasoning（有则显示）
  模型普通输出 / 工具调用

输入
  本次实际消息，可展开完整已保存内容

工具与状态
  调用参数、结果、耗时或真实错误

▸ 技术信息
  rollout/attempt、快照来源、已有门控结果
```

没有独立 reasoning 时不留一块巨大空面板，简短说明后继续显示普通输出。只保存了摘要或截断内容时如实提示。正文按需读取，不嵌入每个图节点对象。

点击结束结果可高亮实际路径，包括真实共享前缀；不能高亮父轨迹中未被继承的后缀。回答列表可以定位同一个结果。第一版不建设独立的并排后缀对比工具。

最终奖励只显示在结果上；没有已计算的节点 credit 时不推测贡献，也不让每个节点重复显示整条奖励。

### 分支说明保持轻量

无分支就显示实际直线，不附加“为什么没分支”面板。真实走到分支点且进行了门控评估时，可以在该节点技术详情查看已有结果。异常沿用错误提示，不堆叠复杂原因分类。

## State and Navigation

- 固定 experiment/run/tree；选中项使用稳定 node_id，不用会变化的显示序号。
- 新旧链接按数据版本解析，旧 answer ID 不当作执行节点 ID。
- 切换执行树/回答列表保留对应结果和阅读位置。
- 新增节点不自动 fitView，不改变选中节点，不按奖励重排路径。
- 状态和内容更新不重新布局；新增后缀只调整必要区域。
- 大树可折叠和分段加载，但标明范围；折叠不改变真实节点与分支数量。
- 详情可关闭和展开；窄屏用抽屉阅读，不挤成三个窄栏。保留键盘入口。

## Implementation Notes

- 2026-09-28 节点拖动：执行树与旧回答来源图共用 `useDraggableNodes`，手动位置只保存在当前挂载图中，不写入后端、Workflow 或训练数据。轮询和追加节点保留已有手动位置，移出当前图的节点释放位置缓存；刷新页面恢复自动布局。拖动只更新位置，复用节点内容与边对象，不重新计算自动布局，标题按钮仍用于打开详情。
- 2026-09-28 连线优化：执行树改用平滑 Bézier 曲线，节点连接口统一高度，避免卡片内容高低不同导致末端突然折弯。完成路径使用绿色细线叠加 CSS 流动短划线；失败路径保持红色、取消或未确认路径保持灰色。流动表示路径方向，不表示训练仍在运行或答案正确。
- 连线组件使用 memo；正文与奖励更新不重建连线对象，拓扑和状态变化分别处理，不增加 React 动画定时器。隐藏的图暂停动画，系统减少动态效果时显示静态线。相关前端快速检查 26 项及 TypeScript/Vite 构建通过，未重新进行服务器视觉验收。
- 2026-09-28：新增 `executionLayout.ts`、`ExecutionGraph.tsx` 和 `ExecutionDetails.tsx`，分别负责纯布局、图呈现和按需内容阅读；旧 `BranchGraph` 保留给 v2 来源记录，未复制训练数据源。
- v3 默认横向图，普通执行、分支、并行汇合与结果使用实际边；状态更新不改变拓扑布局。回答列表只展示 rollout 候选，不将执行节点当作多条回答。
- 查询新增选中节点详情和 v3 节点直达，继续复用有界轮询；尚未开始的候选保留等待状态，不因预分配 result ID 请求不存在的结果节点。
- 前端特征检查 23 项通过，TypeScript/Vite 构建通过；未启动浏览器，真实节点密度、长文本、视口和窄屏效果留待服务器验收。
